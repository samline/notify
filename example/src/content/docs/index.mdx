`@samline/notify` renders toast notifications directly into the DOM. Use the typed package entrypoint with a bundler, the browser subpath as a registry, or the standalone IIFE as `window.Notify`.

## Why Notify?

- **Vanilla-first:** no React, Vue, Svelte, or virtual DOM dependency.
- **Typed public API:** toast variants, promise states, lifecycle controls, snapshots, controllers, and advanced state access.
- **Accessible mechanics:** a polite live list, keyboard focus shortcut, focus-paused timers, native buttons, and reduced-motion CSS.
- **Flexible styling:** one stylesheet, stable `data-*` hooks, per-toast classes, unstyled rendering, and CSS custom properties.
- **Zero runtime dependencies:** ESM, CommonJS, browser-registry, and standalone IIFE builds.
